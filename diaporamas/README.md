# Diaporamas de cours vestibulaires

Bibliothèque de diaporamas Google Slides (pathologies, tests, techniques, traitements), construite et tenue à jour par une équipe de trois agents, à partir de la littérature et de la veille scientifique.

| Fichier | Rôle |
|---|---|
| `regles.md` | Règles communes : niveau, plan type, sources, schémas, construction |
| `chef.md` | Chef de projet, vers 13 h : choisit les sujets, donne les consignes, repère les mises à jour |
| `redacteur.md` | Rédacteur, vers 14 h et 20 h : recherche, rédige et construit un diaporama par passage |
| `relecteur.md` | Relecteur, vers 23 h : contrôle les sources, les chiffres et la forme, corrige ou renvoie |
| `scripts/construire_diapos.py` | Transforme le plan JSON d'un diaporama en requêtes Google Slides homogènes |

Les agents se coordonnent dans l'onglet « Diaporamas » du tableau de veille. Les diaporamas validés sont annoncés dans le mail du matin de la veille.
